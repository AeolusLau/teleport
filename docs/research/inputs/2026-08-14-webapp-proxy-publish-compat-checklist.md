# 企业浏览器访问内网 Web 应用兼容性问题清单

日期：2026-08-14  
适用范围：企业浏览器、云端网关 + Connector 发布内网 Web 应用后的兼容性排查。  
不包含范围：下载拦截、复制限制、脱敏、水印、截屏录屏禁用、文件不落地、二次认证等安全策略与业务流程适配问题。

## 一、核心结论

只要 Web 应用原本不是按“企业浏览器 + 云端网关 + Connector”访问链路设计的，经过云端网关、Connector、域名映射、路径改写、Header/Cookie 处理、HTTPS 终止、跨域和长连接代理后，就可能出现兼容性问题。

这些问题的本质不是安全策略问题，而是内网 Web 应用被云端网关 + Connector 发布后，原有域名、路径、协议、Cookie、Header、跨域和长连接假设发生变化导致的兼容性问题。

标准判断口径：

> 排查时必须按同一请求链路收集证据：浏览器 Network / Console、网关访问日志、Connector 日志、后端访问日志。不能只凭用户说“页面慢”或“页面打不开”判断是网关问题。

## 二、兼容性问题总表

| 类别 | 典型现象 | 根因 |
|---|---|---|
| URL / Path 重写问题 | 页面能打开，API 404；静态资源 404；子路径跳错后端 | 应用原始路径、网关发布路径、后端路由不一致 |
| 绝对地址问题 | 页面资源加载内网 IP；点击后跳回内网域名；接口请求内网地址 | 前端或后端写死了内网域名、IP、端口、协议 |
| 302 / Location 重定向问题 | 登录后跳回内网地址；反复重定向；退出登录跳错地址 | 后端返回的 `Location` 未改写为外部访问地址 |
| Cookie Domain / Path 问题 | 登录成功后仍然未登录；刷新掉线；不同路径会话不共享 | `Set-Cookie` 的 `Domain`、`Path` 与代理后外部域名/路径不匹配 |
| Cookie Secure / SameSite 问题 | SSO 回调失败；iframe 内登录失败；跨站请求不带 Cookie | `Secure`、`SameSite` 与 HTTPS 终止位置、跨站访问方式不匹配 |
| CORS / OPTIONS 预检问题 | 浏览器报跨域；接口预检失败；POST/PUT 请求无法发出 | `Origin`、允许方法、允许请求头、凭据携带规则配置不一致 |
| iframe 嵌入问题 | 嵌入页面空白；监控页/BI 页打不开；控制台报拒绝嵌入 | `X-Frame-Options`、`CSP frame-ancestors`、父子页面域名/协议不一致 |
| HTTP/HTTPS 混用问题 | 控制台报 `Mixed Content`；JS/CSS/API/WebSocket 被浏览器拦截 | 外部 HTTPS 页面中引用了 HTTP 资源或接口 |
| WebSocket 代理问题 | 实时消息断开；监控大屏不刷新；在线协作失败 | `ws/wss` 地址、`Upgrade` / `Connection` 头、超时、路径转发不正确 |
| SSE / 长轮询问题 | 实时通知不稳定；请求一直 pending 后断开 | 网关超时、缓冲、连接保持策略不适配长连接 |
| 前后端分离路径问题 | 首页正常，接口异常；刷新二级路由 404 | SPA 路由、API Base URL、静态资源 Base Path 与发布路径不一致 |
| 多域名应用问题 | 主页面正常，子系统、图片、附件、报表加载失败 | 应用依赖多个内网域名，未全部纳入代理发布或未做域名映射 |
| 静态资源缓存问题 | 页面样式错乱；JS 旧版本；更新后仍访问旧资源 | CDN/缓存头、ETag、路径重写、版本文件缓存不一致 |
| Header 透传问题 | 后端识别不到真实协议/Host；生成错误回调地址 | `Host`、`X-Forwarded-Host`、`X-Forwarded-Proto`、`X-Real-IP` 透传不正确 |
| 认证回调问题 | OAuth/OIDC/SAML 登录失败；回调地址不匹配 | IdP 配置的 Redirect URI 与代理后的外部地址不一致 |
| CSRF 校验问题 | 表单提交失败；接口返回 403 | 后端校验 `Origin`、`Referer`、CSRF Token，与代理后域名不一致 |
| 文件上传问题 | 上传中断；大文件失败；进度条异常 | 网关请求体大小、超时、分片上传、Chunked 传输处理不匹配 |
| 文件下载问题 | 下载文件名乱码；下载失败；预览失败 | `Content-Disposition`、`Content-Type`、Range 请求、流式响应处理异常 |
| Range / 视频流问题 | 视频无法拖动；音视频预览卡顿；大文件预览失败 | `Range`、`206 Partial Content`、流式转发、缓存策略不兼容 |
| 压缩编码问题 | 页面乱码；响应体替换失败；JS 报错 | `gzip/br` 压缩、字符集、响应内容改写顺序处理不当 |
| 响应内容替换副作用 | 某些页面正常，其他页面异常；JS 内容被误替换 | URL/域名替换规则过宽，误改业务响应体或脚本 |
| 特殊端口问题 | 页面访问正常，某些接口失败 | 应用引用非标准端口，代理发布规则未覆盖 |
| 第三方依赖问题 | 地图、验证码、在线编辑器、富文本、报表组件异常 | 应用依赖外部域名、第三方脚本、字体、接口，代理策略未覆盖 |
| 浏览器兼容问题 | 在普通 Chrome 正常，在企业浏览器异常 | 内核版本、User-Agent、浏览器 API、扩展机制差异 |
| 证书链问题 | 页面提示不安全；接口 TLS 握手失败 | 后端证书不完整、自签证书、SNI、证书域名与代理访问域不一致 |
| HSTS / CSP 问题 | 被强制跳 HTTPS；资源被策略拦截 | 应用原有安全头与代理后的访问域名、协议不匹配 |

## 三、最高频问题 Top 10

| 优先级 | 问题 | 典型验证点 |
|---|---|---|
| 1 | URL / Path 重写错误 | API、静态资源、子路径是否命中预期后端 |
| 2 | 302 跳回内网地址 | `Location` 是否包含内网 IP、内网域名、错误端口 |
| 3 | Cookie Domain / Path / SameSite 不匹配 | 登录态是否保持，刷新后是否掉线 |
| 4 | CORS / OPTIONS 预检失败 | `Origin`、方法、请求头、凭据规则是否一致 |
| 5 | iframe 被安全头拒绝嵌入 | `X-Frame-Options`、`CSP frame-ancestors` 是否允许指定父页面 |
| 6 | HTTP/HTTPS Mixed Content | HTTPS 页面是否引用 HTTP 资源、API 或 WebSocket |
| 7 | WebSocket 升级失败 | `Upgrade`、`Connection`、101 状态码、`ws/wss` 路径 |
| 8 | 前后端分离二级路由 / API Base URL 异常 | SPA 刷新、二级路由、API Base Path |
| 9 | 上传下载大文件、分片、Range 请求异常 | 请求体大小、超时、分片上传、`206 Partial Content` |
| 10 | SSO/OAuth/OIDC/SAML 回调地址不匹配 | Redirect URI、外部访问域名、协议、端口 |

## 四、按链路拆分排查对象

| 链路层级 | 必须确认 | 主要证据 |
|---|---|---|
| 浏览器 | 请求 URL、方法、状态码、重定向链、Console 报错、耗时、是否特定浏览器复现 | 脱敏 Network 摘要、Console 错误、浏览器版本 |
| 云端网关 | 发布规则命中情况、路径/Host/Header 改写、访问日志、错误日志 | 请求 ID、实际转发地址、状态码、错误时间 |
| Connector | 到内网应用的连接状态、DNS 解析、TLS、超时、转发日志 | Connector 日志、目标地址、连接耗时 |
| 后端应用 | 请求是否抵达、接收的 Host/Scheme/Path/Header、响应状态 | 后端访问日志、应用错误日志 |
| 响应回程 | `Set-Cookie`、`Location`、CSP、X-Frame-Options、CORS、Upgrade 是否被改写 | 浏览器响应头与后端原始响应头差异 |

## 五、典型问题处理原则

### 1. 不凭体感判断网关问题

页面慢不一定是网关慢，可能是：

- HTTP 对头阻塞。
- 前端资源渲染慢。
- 大文件、图片、视频加载慢。
- 浏览器本地性能问题。
- 后端接口响应慢。
- Connector 到内网应用链路慢。

必须用浏览器 F12、网关日志、Connector 日志、后端日志共同判断。

### 2. 每次只验证一个假设

不要同时改 URL 重写、Cookie、Header、CORS、CSP。  
每次只改一个变量，记录原值、影响范围、验证结果和回退方式。

### 3. 不做过宽修复

不建议作为常规方案：

- 全放开 CORS。
- 删除全部 CSP。
- 删除全部 `X-Frame-Options`。
- 降低 Cookie `Secure` 或 `SameSite` 安全属性。
- 全量响应内容替换。
- 将整个应用或多个应用切为 Bypass。

兼容修复必须精确到域名、路径、Header、Cookie 或接口范围。

### 4. 区分应用失败和代理失败

同一个现象可能来自不同层：

| 现象 | 可能来源 |
|---|---|
| 404 | 网关路径没配、后端路由不存在、前端 Base Path 错 |
| 403 | CSRF 校验失败、CORS 拒绝、后端权限拒绝 |
| 502/504 | Connector 不通、后端不可达、网关超时 |
| 登录循环 | Cookie 不匹配、SSO 回调错误、Session 丢失 |
| 页面空白 | 静态资源 404、JS 报错、CSP 拦截、iframe 拒绝 |

## 六、POC 兼容性验证清单

| 验证项 | 必测内容 |
|---|---|
| 登录认证 | 账号密码、SSO、验证码、短信、MFA、退出登录 |
| 重定向链 | 登录前后、退出后、超时后是否跳到正确外部地址 |
| 首页与菜单 | 首屏、菜单、刷新、返回、二级路由 |
| 静态资源 | JS、CSS、图片、字体、图标、前端 chunk |
| 核心 API | 查询、提交、审批、保存、分页、搜索 |
| Cookie 会话 | 刷新、跨路径、跨子域、长时间会话 |
| CORS 预检 | POST、PUT、DELETE、自定义 Header、携带凭据 |
| iframe 页面 | 报表、监控、BI、大屏、嵌入式子系统 |
| WebSocket/SSE | 即时消息、监控告警、在线协作、实时刷新 |
| 上传下载 | 小文件、大文件、分片上传、批量下载、文件预览 |
| 视频/大文件预览 | Range 请求、拖动进度、断点加载、流式响应 |
| 第三方依赖 | 地图、验证码、富文本、在线编辑器、外部脚本 |
| 性能体验 | 首屏耗时、核心 API 耗时、大文件渲染、弱网表现 |
| 日志闭环 | 浏览器请求、网关日志、Connector 日志、后端日志能否串联 |

## 七、建议沉淀的交付材料

| 材料 | 用途 |
|---|---|
| 应用发布前信息采集表 | 收集域名、端口、协议、认证方式、依赖域名、WebSocket、上传下载等信息 |
| 复杂 Web 兼容性排查 SOP | 标准化 URL、Cookie、CORS、iframe、WebSocket、上传下载排查 |
| 应用兼容性验收清单 | POC 和上线前逐项验证 |
| 变更记录与回退方案 | 记录每次网关规则调整和回退方式 |
| 常见应用模板 | OA、ERP、CRM、BI、监控大屏、前后端分离应用、SSO 应用 |
